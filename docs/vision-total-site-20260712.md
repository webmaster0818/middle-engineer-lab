# ミドルエンジニア転職支援：総合サイトの理想像と実行計画（2026-07-12策定）

## 0. 現状診断（GSC直近28日）
- **3click / 361imp**（新規・立ち上がり期）。資産は既に大規模：company96・salary18・compare48・skill61・knowledge92・review40・cert36・career27・industry27・purpose31・age10（約500ページの網羅済み）。
- **勝ち筋は実証済み**：転職エージェント比較（levtech-vs-* 等）が **pos6-9・CTR17-33%でGoogle1ページ目**。
- **最大の潜在流入**：企業年収ページ（google 267imp・freee 244imp・salary/company-ranking 129imp）が**pos25-35で埋もれCTR0.4%**（P0で冒頭直答box実装済＝効果測定待ち）。
- 需要の質：企業×年収/クチコミ（"aws クチコミ"45imp）・40代転職・外資/big-tech。
- **差別化の核**：企業年収を**有価証券報告書の実額**で提示（推計でない一次情報）＝競合の年収まとめ記事に無い強み。

## 1. 理想像（Vision）
> **「30-40代のミドルエンジニアが、①自分の市場価値・年収相場（有報実額）②どの転職サービスが自分に合うか ③スキル・資格・キャリアの伸ばし方 ④企業の実態（年収・選考・技術）を、一次情報にもとづいて判断できる。“ミドルエンジニア転職の総合ナビ”」**

### 3本柱
1. **年収データ（市場価値がわかる）**：有報準拠の企業年収DB＋年代別/職種別/業界別salary＝「この会社・この年代はいくら」を一次情報で。差別化＝**有報実額（金融庁提出値）**。
2. **サービス比較（意思決定支援）**：転職エージェント/サイトの1対1比較（勝ち筋・page1実証）。
3. **キャリア知識（不安解消）**：40代転職の現実/スキル/資格/面接/年収交渉（knowledge92）＝ミドル特有の不安に直答。

## 2. 実行計画（優先順位）

### P0【最速回収】高表示企業ページのCTR/ランク改善
- google 267imp・freee 244imp 等の高表示企業ページに**冒頭直答box（「◯◯の年収は？→有報実額」）を実装済**。
- 次：7/14前後の効果測定 → 効いた型を**残り企業ページへ横展開**＋クチコミ×年収の直答強化（"aws クチコミ"意図）。
- salary/company-ranking を**企業への内部リンクハブ**に（P2の年収DB主役化と連動）。

### P1【勝ち筋拡張】エージェント比較クラスタの横展開
- levtech/findy/doda/recruit の勝ちクラスタに、実需要の1対1比較を計画的に追加（type-it-vs-levtech/geekly-vs-recruit/findy-vs-green 等を実装済・継続）。
- フリーランス系サブクラスタ（levtech-freelance系）も厚くする。

### P2【差別化】有報年収DBの主役化
- 企業年収を「**企業比較・年代比較・業界比較**」の横断表で見せ、salary-ranking を起点に全企業ページへ送客。
- 「◯◯ 年収」「◯◯ クチコミ」クエリの受け皿を有報実額で統一。

### P3【網羅性】6軸の相互リンク網
- 企業×年収×サービス比較×スキル/資格×キャリア知識×年代/業界。既に各軸のページは豊富 → **相互内部リンクで束ね、クロール・評価を集中**（現状は個別ページが孤立気味）。

### P4【E-E-A-T・鮮度】
- 一次情報（有報・公式）・出典・確認日を全ページ徹底（年収は決算期明記）。有報更新期の年次リフレッシュを運用化。

### P5【CV動線】
- 「年収相場/不安クエリ → 比較 → エージェント登録」を全ページで貫通。

## 3. 測定と運用
- 立ち上がり期：**順位（pos）とCTR**を主指標に。P0の企業直答box効果を7/14ゲートで判定し勝ち型を横展開。
- 勝ち筋（比較クラスタ・有報年収）を軸に、page3→page1の浮上を週次で追う。

## 4. 90日ロードマップ（目安）
- 〜2週：P0効果測定＋企業ページ横展開（高表示から）
- 〜1ヶ月：P1（比較クラスタ拡張）＋P2（有報年収DB主役化・内部リンクハブ）
- 〜2ヶ月：P3（6軸の相互リンク網）＋薄いページのindex品質整理
- 〜3ヶ月：年収DB×比較×知識が相互に評価を支え合う“総合ナビ”として確立
