## cert/（TOP「エンジニア 資格 転職 おすすめ」）
- 冒頭結論「30-40代は資格より実務経験。資格は補強材」（Information Gain）
- 国家資格(IPA系・普遍/有効期限なし※支援士除く) vs ベンダー資格(AWS/Cisco/LPI・実務直結だが有効期限: AWS/CCNA 3年, LPIC/LinuC 5年)
- 目的別マトリクス: マネジメント→PMP / セキュリティ→支援士 / クラウド→AWS / インフラ未経験→CCNA・LPIC

## cert/pmp
- 主催PMI / 受験資格: 大卒=PM経験36ヶ月+35時間研修, 非大卒=60ヶ月+35時間 / 受験料 会員$405・非会員$655 / 180問3時間50分 / 更新3年ごと60PDU / 国内取得者約48,811人(2025年1月時点・Geekly集計)
- 年収【権威=PMI公式 Salary Survey 13th Edition/2023】: 日本のPMP保有者 中央値891万円 vs 非保有817万円。年代別 30代949万/40代1,212万/50代1,217万（平均・賞与含む）
- 参考値(Geekly2025集計): 取得者平均896万、20代483/30代721/40代947/50代1,000万超
- 30-40代価値: 受験資格自体がPM実務36ヶ月以上→構造上ミドル向け。経験の客観証明＋高単価案件フィルタ通過。日経「転職に役立つ資格」上位

## cert/security-specialist（情報処理安全確保支援士）
- 主催IPA(経産省管轄) / 受験料7,500円 / 合格率 2025秋22.3%・2025春19.0%(IPA令和7年度) / 午前Ⅰ・Ⅱ多肢+午後記述 各60点以上 / 応用情報合格者は午前Ⅰ2年免除 / 2026年度CBT移行予定
- 維持費(正直に書く): 登録約20,000円+3年で最低約11.5万円〜(毎年オンライン講習2万×3+3年に1回実践/特定講習5-16万)。名称独占だが独占業務はまだ無い
- 政策: 経産省「2030年までに登録者5万人」目標
- 年収【公的=経産省IPA調査】ITスペシャリスト(DB/NW/セキュリティ等)平均758.2万円(レベル6/7は1,000万超)。参考値600-1,300万(Midworks等・レンジ広く断定回避)
- 30-40代価値: サイバー攻撃増で需要拡大。実務(運用/監査)＋国家資格で信頼性

## cert/aws（AWS認定 SAA中心）
- 主催AWS / SAA-C03 / 65問130分 / 合格720(1000満点) / 受験料 日本アソシエイト20,000円(2024/4/1改定) / 有効3年
- 注意喚起(定番): 資格だけでは年収上がらない、実務2-3年とセット
- 年収: SAA保有者平均572万/SAP保有者745万(technolog集計・参考値)。AWSエンジニア平均約509万・中央値約550万(レバテック2026年4月)。経験別 3-5年450-700万/5-10年700-1000万/10年以上900-1500万
- 30-40代価値: オンプレ/インフラ実務×AWSの掛け算で評価。手当・スカウト増の声

## cert/applied-info（応用情報技術者）
- 主催IPA / 7,500円 / 合格率 2025秋24.5%・2025春22.1%(IPA令和7年度) / 午前多肢80問+午後記述 各60点以上 / 合格で高度試験・支援士の午前Ⅰ2年免除 / 2026年度CBT化予定
- 年収: 保有者平均約520万(集計・参考値)。「保有者は無資格IT技術者比15-20%高」(STUDYing・断定回避)
- 30-40代価値: 上流(設計/PM)への土台、自己研鑽の証明、資格手当対象になりやすい

## cert/basic-info（基本情報技術者）
- 主催IPA / 7,500円 / CBT通年 科目A90分+科目B100分 各1000点中600点以上IRT / 合格率 新制度平均約47.1%(42-47%)
- 年収: 取得者600万前後との集計あるが母集団不明・参考値。給与所得者平均461万(国税庁令和6年分)との対比。「単体で年収一気UPは稀」が共通見解
- 30-40代価値: 経験者には基礎すぎ単体武器性低い。**異業種→IT転職の30-40代**には最低限の知識証明として有効（対象読者で評価分ける）

## cert/ccna
- 主催Cisco / 200-301 / 120分 / 受験料300USD(約42,900-47,000円・為替変動) / 合格点非公開(通説825/1000・約70%は"目安"と明記) / 有効3年 / 日英
- 年収(インフララボ集計・参考値): 未経験+無資格280-320万/未経験+CCNA330-370万。運用350-450万/構築設計500-700万。企業平均385.1万(2025)
- 30-40代価値: 主に未経験〜20代向け。30-40代未経験は「資格＋なぜこの年齢でIT転職か」の納得感要。経験者には基礎証明。年代別に評価分ける

## cert/lpic（LPIC/LinuC）
- LPIC=LPI(国際)/LinuC=LPI-Japan(国内特化)。レベル1=101+102の2試験 / 各16,500円(計33,000円) / 有効5年 / LPIC合格500/800点
- LinuCは国内特化で仮想化/クラウド(AWS/Docker/K8s)出題充実。実務評価は両者同価値
- 年収(エイジレス思考集計・参考値): LPIC1約474万/LPIC2約618万/LPIC3約696万。未経験+LPIC1/LinuC1取得者の平均内定年収370.4万(無資格未経験比+50万)(インフララボ)
- 30-40代価値: Linuxはインフラ/クラウド基盤で需要安定。主に未経験〜若手入口。経験者は上位レベル+実務で価値。国内中心ならLinuCで十分
